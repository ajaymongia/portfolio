# Project thumbnails

Drop a cover image here for any project, then point `thumb` at it in
`data/projects.js`:

```js
thumb: '/img/work/kfc.jpg',
```

Any project without a `thumb` falls back to the generated abstract cover,
so the site never shows a broken or empty card.

Recommended: 1600 × 1000 (8:5), JPG or WebP, under ~300 KB.
